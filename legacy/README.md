# Legacy materials

Эти файлы сохранены только для истории и сравнения.

- старые документы содержат устаревшие слои и местами неверную физическую нумерацию контактов;
- `usb-hid-keyboard` использует другую архитектуру и не поддерживает Text Input protocol v2;
- `src/MacroPad.v1.legacy.txt` — предыдущая serial-прошивка;
- `build-v1.ps1` не следует использовать для новой версии.

Для сборки и подключения используйте только файлы из корня проекта, `src/`, `include/`, `docs/` и `pinout.csv`.
