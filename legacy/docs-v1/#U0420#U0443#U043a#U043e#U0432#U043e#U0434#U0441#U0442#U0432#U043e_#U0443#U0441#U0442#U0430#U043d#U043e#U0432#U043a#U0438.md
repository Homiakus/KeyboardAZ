# Manual PlatformIO Dependencies Installation

## Why installation is slow

PlatformIO downloads and installs:
- **Toolchain** (GCC for ARM): ~500-800 MB
- **pico-SDK**: ~200-300 MB  
- **Arduino framework** (earlephilhower core): ~100-200 MB
- **Libraries** (Adafruit TinyUSB + dependencies): ~50-100 MB

Total: **1-3 GB** depending on what's already cached.

## Manual Installation Methods

### Method 1: Install packages separately (recommended)

Run these commands one by one to see progress:

```powershell
# Install toolchain
python -m platformio pkg install --tool toolchain-gccarmnoneeabi

# Install pico SDK
python -m platformio pkg install --tool framework-arduino-pico

# Install platform (this will pull from GitHub)
python -m platformio pkg install --platform "https://github.com/maxgerhardt/platform-raspberrypi.git"

# Install library
python -m platformio lib install "adafruit/Adafruit TinyUSB Library"
```

### Method 2: Use PlatformIO CLI with verbose output

```powershell
python -m platformio pkg install -e pico -v
```

The `-v` flag shows detailed progress.

### Method 3: Pre-download and cache

PlatformIO caches packages in:
- Windows: `%USERPROFILE%\.platformio\packages\`
- You can check what's already downloaded there

### Method 4: Use faster mirror (if available)

Some packages can be downloaded from alternative sources, but PlatformIO typically uses its own CDN which should be fast.

## Speed Optimization Tips

1. **Check existing cache**: 
   ```powershell
   dir "$env:USERPROFILE\.platformio\packages"
   ```

2. **Use wired connection**: WiFi can be slower for large downloads

3. **Run during off-peak hours**: GitHub/CDN may be faster

4. **Install once, reuse**: After first installation, PlatformIO reuses cached packages

5. **Parallel installation**: The script already uses `PLATFORMIO_BUILD_JOBS` for parallel builds, but downloads are sequential

## Verify Installation

After installation, verify packages are installed:

```powershell
python -m platformio pkg list
```

You should see:
- `toolchain-gccarmnoneeabi`
- `framework-arduino-pico` 
- Platform packages for `raspberrypi`

## Troubleshooting

If installation fails or is very slow:

1. **Check internet connection**: Test with `ping github.com`

2. **Check PlatformIO version**: 
   ```powershell
   python -m platformio --version
   ```
   Update if needed: `pip install --upgrade platformio`

3. **Clear cache and retry**:
   ```powershell
   python -m platformio pkg uninstall --all
   python -m platformio pkg install -e pico
   ```

4. **Use proxy if behind firewall**: Set environment variables:
   ```powershell
   $env:HTTP_PROXY = "http://proxy:port"
   $env:HTTPS_PROXY = "http://proxy:port"
   ```
