## Оптимизация раскладки букв

Раскладка букв в слое 1 оптимизирована с учетом частоты использования букв в английском языке:
- **Указательный палец** (индексы 0-5): самые частые буквы - E, T, A, O, I, N
- **Средний палец** (индексы 6-10): частые буквы - S, H, R, D, L
- **Безымянный палец** (индексы 11-15): средние по частоте - U, C, M, F, G
- **Мизинец** (индексы 16-21): редкие буквы - P, B, V, K, J, Q

Такое распределение обеспечивает:
- Улучшенную эргономику (наиболее используемые буквы на удобных кнопках)
- Повышение скорости набора текста
- Снижение усталости при длительной работе

## Примечания

- **Физический GPIO** - номер GPIO пина RP2040, к которому припаяна кнопка
- **Логический индекс** - индекс в массиве `buttonPins[]` и в обработке кнопок
- **Пин Pico** - физический номер пина на Raspberry Pi Pico (40-пиновый разъем)
- **Слой 1** - маппинг клавиш в слое "Буквы" (оптимизированная раскладка по частоте использования)
- **Частота** - процент использования буквы в английском языке

## Как использовать

При нажатии физической кнопки на GPIO X:
1. Программа читает состояние GPIO X
2. Находит его позицию в массиве `buttonPins[]` - это логический индекс
3. Отправляет логический индекс в приложение
4. Приложение использует логический индекс для определения клавиши по слою
