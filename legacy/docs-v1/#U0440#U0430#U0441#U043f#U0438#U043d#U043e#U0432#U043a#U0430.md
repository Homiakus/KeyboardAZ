# Припайка кнопок к пинам RP2040 (22+4)

Схема: кнопка между **GPIO** и **GND**. В коде: `INPUT_PULLUP`, нажатие = **LOW** (замыкание на GND).

**Не используем:** GPIO 23, 24, 25 (на Pico часто под Flash).

---

## Сборка прошивки

**Windows:**

```powershell
cd "путь_к_папке_Software"
.\build.ps1
```

или двойной клик по `build.ps1`. Скрипт автоматически обходит ExecutionPolicy. Меню: (1) установка платформы/зависимостей, (2) сборка, (3) копирование UF2 на RPI-RP2, (4) собрать и скопировать. Сборка компилирует файлы из `src\`, запускает `pio run -v`; результат → `.pio\build\pico\firmware.uf2` и `Hapticpad_22+4.uf2`. Первый запуск (п. 1 или 2) может занять 10–30 мин (платформа, тулчейн, pico-SDK).

**Вручную:** `pio run` или `python -m platformio run` из папки `Software`. Плата `pico`, исходники в `src/`.

**Arduino IDE:** ядро **Arduino-Pico** (Earle Philhower), плата Raspberry Pi Pico. Открыть `src/MacroPad.ino`. Заливка: UF2 при удержании BOOTSEL.

## Как паять

- **Один вывод кнопки** → **GPIO** (номера в таблице).
- **Второй вывод кнопки** → **GND**.

Резистор не нужен — включён внутренний pull-up.

## Нумерация на Raspberry Pi Pico (вид сверху, USB вниз)

**⚠️ ВАЖНО:** Схема показывает реальную физическую распайку (GPIO пины), а не логический порядок.

```
        [USB]
    ─────────────
 3V3  [1]  [2]  5V    — не для кнопок
 GP0  [3]  [4]  GP1   ← INDEX_3, INDEX_4
 GP2  [5]  [6]  GP3   ← INDEX_1, INDEX_5
 GP4  [7]  [8]  GND
 GP5  [9]  [10] GP6   ← MIDDLE_4, MIDDLE_1
 GP7  [11] [12] GP8   ← INDEX_6, MIDDLE_5
 GND  [13] [14] GP9   ← RING_2
 GP10 [15] [16] GP11  ← RING_3, PINKY_6
 GP12 [17] [18] GP13  ← RING_1, RING_4
 GND  [19] [20] GP14  ← PINKY_2
 GP15 [21] [22] GP16  ← PINKY_5, PINKY_1
 GP17 [23] [24] GP18  ← RING_5, PINKY_3
 GND  [25] [26] GP19  ← PINKY_4
 GP20 [27] [28] GP21  ← MIDDLE_3, INDEX_2
 GP22 [29] [30] GP26  ← Thumb_1, Thumb_2
 GP27 [31] [32] GP28  ← Thumb_3, Thumb_4
 GND  [33] [34] GND
 ...
```

Все **GND** (4, 6, 8, 13, 19, 25, 33, 34, 38, 40 и др.) можно объединить в общую шину — к ней припаивать вторые выводы всех кнопок.

## CSV (файл `pinout.csv`)

Колонки: `Тип`, `Индекс`, `GPIO`, `Кнопка`, `Палец`, `Пин_Pico_40`. 

**⚠️ ВАЖНО:** Физическая распайка не следует последовательному порядку GPIO. Реальное соответствие:
- **Указательный:** INDEX_1…INDEX_6 (6) → GPIO 2, 21, 0, 1, 3, 4  
- **Средний:** MIDDLE_1…MIDDLE_5 (5) → GPIO 6, 7, 20, 5, 8  
- **Безымянный:** RING_1…RING_5 (5) → GPIO 12, 9, 10, 13, 17  
- **Мизинец:** PINKY_1…PINKY_6 (6) → GPIO 16, 14, 18, 19, 15, 11  
- **Большой:** Thumb_1…Thumb_4 (4) → GPIO 22, 26, 27, 28

Для детальной таблицы см. [pinout_physical.md](pinout_physical.md).
