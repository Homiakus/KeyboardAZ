# USB HID Keyboard + Mouse — RP2040 Azeron Keypad

Прошивка для RP2040 (Raspberry Pi Pico), превращающая кастомный кейпад Azeron-стиля в USB HID клавиатуру + мышь. Без промежуточного ПО на хосте.

---

## Архитектура

```
22 основных кнопки  ─┐
 4 thumb-кнопки      ─┼─▶  RP2040  ─▶  USB HID Keyboard + Mouse
                      │     250 мкс scan
                      │     5 мс debounce
                      └─▶  4 слоя (latched)
```

**Слои**: переключаются 3-клавишными chord'ами (latched, не momentary).  
**Thumb-кнопки**: фиксированные функции на всех слоях (Space, Enter, Lang, Backspace).  
**Мышь**: I_2 = ЛКМ, M_2 = ПКМ — работают на всех слоях.

## Переключение слоёв

Слой меняется chord-сочетанием из 3 кнопок (нажать одновременно за 35 мс):

| Слой | Chord |
|------|-------|
| L0 | I_1 + M_1 + R_1 |
| L1 | I_2 + M_2 + R_2 |
| L2 | I_3 + M_3 + R_3 |
| L3 | I_4 + M_4 + R_4 |

Слой **фиксируется** (latched) — не нужно удерживать.

## Chord-система (редкие буквы)

Для доступа к редким буквам используются **двухклавишные chord'ы**: нажмите обе кнопки одновременно (или быстрым слайдом) в пределах **35 мс**.

Как это работает:
1. Нажимается первая кнопка → её обычный символ отправляется
2. В течение 35 мс нажимается вторая → обычный символ **отменяется**, отправляется chord-результат
3. При отпускании любой кнопки chord-результат отпускается

## Русский слой

Русский слой отправляет HID keycode'ы раскладки ЙЦУКЕН. На хосте должна быть активна **русская раскладка ОС**. Используйте **Thumb_3** (Win+Space) для переключения.

## Тайминги

| Параметр | Значение | Описание |
|----------|----------|----------|
| `DEBOUNCE_MS` | 5 мс | Подавление дребезга |
| `COMBO_TERM_MS` | 35 мс | Окно для chord-сочетаний |
| `LAYER_SWITCH_TERM_MS` | 35 мс | Окно для переключения слоёв |
| `STARTUP_GUARD_MS` | 750 мс | Защита от ложных срабатываний при старте |
| `SCAN_IDLE_US` | 250 мкс | Пауза между циклами сканирования |

Целевая задержка: **6–9 мс** для одиночной кнопки.

## Ограничения

- USB HID keyboard: до **6** одновременных не-модификаторных клавиш
- Consumer/media key: одна за раз
- Мышь: один HID endpoint, scroll = один тик на нажатие
- Reference count для дублирующихся keycode'ов между кнопками
