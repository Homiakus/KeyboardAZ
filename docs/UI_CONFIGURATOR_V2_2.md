# Hapticpad Go UI Configurator v2.2

## Назначение

Встроенный конфигуратор заменяет ручное редактирование `layout-v2.json`. Он работает с фактическим semantic-протоколом прошивки v2 и позволяет управлять всеми пользовательскими назначениями клавиатуры.

Один профиль содержит:

- 22 основные физические клавиши;
- 2 языка: English и Русский;
- 8 режимов каждой основной клавиши;
- 3 настраиваемых коротких действия больших клавиш;
- фиксированное системное переключение языка на `THUMB_3`.

Итого доступно 352 назначения основных клавиш и 3 thumb-tap действия на профиль.

## Экран «Настройка клавиш»

### 1. Профили

Профиль является полной независимой раскладкой. Поддерживаются:

- выбор профиля для редактирования;
- переименование;
- дублирование;
- немедленная активация;
- удаление, кроме последнего профиля;
- импорт проверенного JSON;
- экспорт JSON с временной меткой;
- возврат к последнему сохранённому состоянию.

Активный профиль отмечается непосредственно на вкладке.

### 2. Язык и режим

Для основных клавиш доступны два языка и восемь режимов:

| Режим | Физический жест |
|---|---|
| Буквы | основная клавиша |
| Заглавные | `THUMB_1 + main` |
| Редкие | `THUMB_3 + main` |
| Заглавные редкие | `THUMB_1 + THUMB_3 + main` |
| Пунктуация | `THUMB_2 + main` |
| Инженерные знаки | `THUMB_1 + THUMB_2 + main` |
| Цифры | `THUMB_4 + main` |
| Инженерные числа | `THUMB_1 + THUMB_4 + main` |

Переключение режима в UI не меняет прошивку. Оно выбирает таблицу назначений, которую пользователь редактирует.

### 3. Визуальная схема

Клавиши сгруппированы по пальцам в геометрии проекта:

- INDEX — 6;
- MIDDLE — 5;
- RING — 5;
- PINKY — 6.

Каждая плитка показывает:

- физическое имя;
- текущее действие выбранного языка и режима;
- выделение выбранной клавиши;
- зелёную подсветку при реальном нажатии подключённого устройства.

### 4. Большие клавиши

| Клавиша | Настраивается | Фиксированная роль удержания |
|---|---|---|
| THUMB_1 | короткое действие `space` | Shift |
| THUMB_2 | короткое действие `enter` | Пунктуация |
| THUMB_3 | переключение EN/RU фиксировано прошивкой | Редкие буквы |
| THUMB_4 | короткое действие `backspace` | Цифры |

Содержимое всех hold-режимов настраивается через таблицы 22 основных клавиш. Поэтому фиксируется только способ выбора режима, а не выводимые символы.

## Типы действий

### Нет

Клавиша отключена в выбранном режиме.

### Текст

Любая Unicode-строка: одна буква, знак, слово или фраза.

Примеры:

```text
Ё
±
ГОСТ 2.XXX
```

### Клавиша

Одиночное логическое действие.

```text
space
enter
backspace
f5
mouse_left
```

### Сочетание

Клавиши разделяются знаком `+`.

```text
ctrl+s
ctrl+shift+z
alt+f4
```

### Команда

Команда ОС или путь к программе. Это фоновое действие и оно не блокирует realtime-печать. Использовать только доверенные команды.

### Макрос

Один шаг на строку:

```text
ctrl+c
text:готово
enter
cmd:notepad.exe
```

Пустые строки и строки, начинающиеся с `#`, игнорируются. Вложенные макросы запрещены.

## Живое применение и сохранение

После нажатия «Присвоить», «Очистить» или «По умолчанию» рабочая раскладка немедленно заменяется через потокобезопасный resolver. Перезапуск приложения не требуется.

Состояния:

1. **Рабочее** — уже используется клавиатурой.
2. **Черновик** — рабочие изменения ещё не закреплены на диске.
3. **Сохранённое** — файл `layout-v2.json` обновлён атомарной заменой.

Кнопка «Сохранить изменения» записывает черновик. «Отменить» восстанавливает последнюю сохранённую версию и одновременно возвращает её в resolver.

## Проверка и диагностика

Для каждого режима выводятся:

- число назначенных клавиш;
- число пустых клавиш;
- повторяющиеся действия;
- число фоновых команд и макросов.

Кнопка «Проверить» выполняет действие из редактора без изменения раскладки. Для команд и макросов она действительно запускает действие, поэтому использовать её следует осознанно.

## Файлы

Основной файл:

```text
~/.hapticpad/layout-v2.json
```

Экспорт:

```text
~/.hapticpad/exports/hapticpad-layout-YYYYMMDD-HHMMSS.json
```

Импорт проходит строгую JSON-проверку, проверку версии, языков, режимов, физических имён клавиш и всех действий. Импортированная раскладка сразу становится рабочим черновиком, но основной файл заменяется только после сохранения.
